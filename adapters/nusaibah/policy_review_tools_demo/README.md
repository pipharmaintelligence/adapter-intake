# Synthetic policy review tools demo

This development asset supplies domain methodology and scope to the same `nusaibah.structured_review_toolkit:0.1.0` callable used by the other demo. It contains no chunking, evidence-verification or assembly implementation.

Use synthetic fixture/dummy inputs only. No Agents, providers, memory mutation, real lake bindings or publication are introduced. Source/coverage structural completion does not establish semantic authority or independent quality.

The existing signed `local_worker` runtime must attach the declared `review_toolkit` callable role. A plain dictionary or an unregistered catalog cannot substitute for that capability. The initial manifest intentionally permits only `local_worker`.

See the [shared toolkit](../structured_review_toolkit/README.md) and [developer guide](../structured_review_toolkit/DEVELOPER_GUIDE.md). Tests and the offline signed-worker proof demonstrate that both domains use the same installed child entry hash. Live admission and production activation remain separate.
