# First-package publication in 0.1.38

This release changes first-package publication only. It preserves the one-pass
enrichment, paragraph/subsection packing, critics, recovery, benchmark-disabled
contract, finite budgets and the existing 0.1.37 update helper.

An absent memory package does not block review. A validated nonempty candidate
is rendered as a complete portable SKILL.md with its exact citation annotations.
The admitted mutable role invokes the trusted generic initializer. Core's
existing upload/init, provider transfer and upload/complete path receives
partition_write_mode=if_absent. Existing packages are never overwritten by
initialization; normal updates continue through selected-revision changesets.

First upload has upload/operation provenance and verified Skill readback. It has
no fabricated Dynamic Skill change ID/history. Failed or ambiguous completion
is reported without a second upload. Readback failure preserves the known upload
receipt. An optional methodology with no learning candidate remains absent and
is reported as no_change; no empty learning package is invented.

The trusted first-package bridge is a prerequisite. Deliver through official
workflow promotion; do not overwrite installed adapters or bump the runtime
version manually. Provider-free tests cover absent, present, stale, rejected,
ambiguous and readback-failure cases. No additional reflection passes are added.
