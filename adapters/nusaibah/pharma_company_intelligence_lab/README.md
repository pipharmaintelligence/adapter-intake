# Nusaibah Pharma Company Intelligence Lab

Canonical adapter-intake source for `nusaibah.pharma_company_intelligence_lab`.

## Current stage

`0.1.0` foundation establishes the batch input contract, canonical dossier DTO hierarchy, portable methodology Skill, output admission schema, and Dynamic Skill partition declarations. The foundation adapter intentionally performs zero provider calls and zero memory mutations.

Live Vertex Agent definitions, grounded research, critique/synthesis, Dynamic Skill apply, and dossier publication remain later checklist gates and must not be inferred from foundation importability.

## Batch contract

The target launch variable is a bounded `company_ids` array such as `[13, 59]`. Assets/Core must resolve the governed `companies` input before Python starts. The adapter validates exact requested/resolved ID parity and then processes company contexts independently.

## Format ownership

`dossier_contract.py` owns exact section IDs, subsection IDs, titles, and order. Agents will return machine IDs and content only. Titles and hierarchy are rendered deterministically by the adapter so report structure cannot drift by provider, company, or run.

## Promotion ownership

This adapter-intake folder is the reviewed source package. Published Assets materialization must be produced through the pinned adapter-intake promotion workflow rather than by hand-editing the packaged Assets directory.

See `DEVELOPMENT_CHECKLIST.md` for stage-qualified build and proof gates.
