# Company enrichment 0.1.55

This immutable version hardens the evidence transformation that follows model
response validation. Native grounding can associate one claim with more than
the existing 24-reference allowance even when the model response itself fits.

Native support is deduplicated by admitted URI and stops expanding when a 25th
distinct reference proves overflow. The entire affected claim is withheld from
accepted evidence. The adapter never accepts the first 24 references of an
overflowing claim. Independent claims continue through the existing evidence
and critic checks; publication reports incomplete research and retains the
existing review annex behavior.

Post-transformation locator and qualifier fields must satisfy the unchanged
claim-index limits. Malformed optional grounding metadata adds no authority.
Exact source passages still use the admitted reader and exact-span toolkit.
Provider-generated support is not a literal source quotation and still requires
the claim critic. Identity, contract, admission and mutation authority checks
remain strict; this containment is limited to claim evidence leaf fields.

Content-free observations report `claim_evidence_bounds`, a stable rule, field,
hashed claim identity, allowed count and observed lower-bound count. The count
is a lower bound because expansion stops as soon as overflow is established.
These observations are retained in the existing source-retrieval diagnostics.
No additional model call, provider retry or source-repair loop is introduced.

All nine Gemini 4 Argon role contracts, the allowance of 15 concurrent agent
calls, absolute call and time budgets, fresh Dynamic Skill baselines and
publication readback checks remain those of 0.1.54. Historical executable and
manifest version definitions are preserved.

Provider-free proof covers the original fatal overflow, exact boundaries,
duplicate native references, malformed metadata, parallel pieces, unchanged
normal publication content and safe publication of independent claims.

A failed 0.1.54 run is not automatically replayed into this version. Certified
stage reuse requires the same version and read-only effects; company enrichment
has mutation-capable Skills. Preserve the failed run and checkpoint, qualify
and admit this version, and obtain explicit recovery authorization before
repeating potentially paid research. Promotion and CI are not live execution
or deployment proof.
