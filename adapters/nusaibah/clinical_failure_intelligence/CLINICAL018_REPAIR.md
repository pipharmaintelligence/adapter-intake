# Clinical 0.1.8 scientific completion repair

## Confirmed defects
The retained 0.1.7 run completed transport successfully but generated no hypotheses.
Global outcome-reference closure repeated 278 windows before any assigned window;
every singleton exceeded both the admitted character and adapter byte budgets.
Three researcher items failed literal span checks and nine critic verdicts added
references outside their candidate's closed evidence sets. These remain scientific
validation errors, not reasons to discard valid work or certify unsupported claims.

## Implemented contracts
- Full source windows, research claims and outcomes remain once in canonical output.
- Hypothesis packets carry complete assigned source windows and complete selected
  research claims, plus a complete provisional outcome identity/value index with
  canonical digests. The index is not evidence and cannot grant acceptance.
- An unfit common packet produces one explicit deferred work unit, not one per row.
- Critic schemas constrain support and counterevidence separately for each candidate.
- At most four explicit business correction tasks per run, once per rejected unit,
  only when enable_refinement=true; every call shares the existing 64-call budget.
  Original stage outputs/digests and correction lineage remain auditable. Corrections
  pass the same validators. No provider-unknown-outcome or security retry is added.
- Product memory preview uses complete already reviewed derived findings, exact
  source IDs and a canonical ledger digest. It has no raw-source or new-science
  authority. Editorial batches preserve whole old paragraphs, check new text against
  scoped reviewed findings and independently review each edit. Aggregate edit limits,
  target collisions, deduplication and existing digest guards remain enforced.
- No source configuration, Core policy, credential, Dynamic Skill write, publication
  or clinical success probability is changed. Models, thinking levels, fixed Skill,
  reflection bounds, source adapter versions and local_worker/ECS manifests persist.

## Qualification boundary
Provider-free tests and saved-run packet measurements establish engineering behavior.
They do not establish future model quality, scientific accuracy or live deployment.
Promotion, new Agent 1.6.0 admission, source bindings and a separately authorized live
run remain release gates. Execution success is distinct from clinical quality.
